Louisiana 5-day notice to vacate (rent not paid)

After you dissolve the lease for unpaid rent, tells the lessee to leave within 5 days of delivery.

Updated November 7, 2026

Sign in on the web

The facts.

  • WhenRent is past due and you have ended the lease (Louisiana has no grace period).
  • The lawLa. Code Civ. Proc. art. 4701; La. Civ. Code art. 2704; La. Code Civ. Proc. art. 4703; La. Code Civ. Proc. art. 5059
  • StageNotices before court

What to know.

  • Louisiana gives no statutory time to pay: when rent isn’t paid when due, the lessor may dissolve the lease (La. Civ. Code art. 2704) and then send this notice. If you’d rather give the lessee a chance to pay first, the Civil Code allows a notice to perform within a reasonable time, with a warning that the lease will otherwise be dissolved (art. 2015); NOHM’s notice doesn’t do that.
  • Rent is due at the beginning of each period unless the lease says otherwise (La. Civ. Code art. 2703); there is no grace period.
  • The 5 days leave out legal holidays because the period is under 7 days (La. Code Civ. Proc. art. 5059(C)). Whether Saturdays are legal holidays (La. R.S. 1:55) wasn’t confirmed, so NOHM skips Saturdays and Sundays too: the longer, safer count.
  • Many Louisiana leases contain the lessee’s written waiver of the notice to vacate. If yours does, you may file the rule to show cause as soon as the lessee’s right of occupancy ends (La. Code Civ. Proc. art. 4701).
  • Hand it to the lessee and keep proof of delivery. You may attach it to a door of the home only if the home is abandoned or closed, or you don’t know where the lessee is (La. Code Civ. Proc. art. 4703). The Code names no mail delivery, so NOHM doesn’t offer it.
  • Under an oral lease, a written demand for the rent that gives the correct amount makes the lessee liable for your attorney fees if it isn’t paid within 20 days after delivery (La. R.S. 9:3259). It can go by certified mail, by hand, or tacked on the door.
